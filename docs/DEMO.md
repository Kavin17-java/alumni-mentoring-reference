# Classroom demo walkthrough

This walkthrough uses only the fictional database rows loaded by the app. Run the local server using the README steps, then open http://127.0.0.1:5000.

1. On Home, choose Student and Riya Student, then save the selection.
2. Open Directory. The list should include 14 consenting alumni. Search Technology and python together to see combined filters. Profiles without consent are excluded.
3. Open Suggestions. The student’s target industry and shared keywords produce up to three scored recommendations with the reasons shown.
4. Open Aarav Demo and send a message of at least 10 characters. The request appears as Pending on Requests. A duplicate pending request to the same person is refused.
5. Change the request to Accepted, then to Completed. Trying to move a completed request back to another status is rejected.
6. Open Reports. The initial fictional sample has four requests across Pending, Accepted, Declined and Completed. Download CSV to inspect the same report as a spreadsheet-compatible file.
7. Register a fictional alumni profile without selecting consent, then search the directory to confirm it is hidden. With an Alumni demo role, a consenting profile detail page also displays the consent withdrawal control.

The pages are the live demo; no screenshot or student contribution record is claimed by this walkthrough.
