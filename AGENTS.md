# Project rules
- Keep code readable for Semester I beginners; use functions, loops and simple SQL.
- Use Flask, sqlite3, Jinja, HTML, CSS and Bootstrap CDN only.
- Validate every submitted value on the server and parameterise SQL.
- Use fictional demonstration data only; do not add real identities.
- Only consenting alumni can appear in public views or receive requests.
- Preserve the three-table schema and explain any concepts beyond the syllabus.
- Run pytest when asked; do not claim unexecuted checks passed.
- Do not fabricate team contributions, reviews, verification records or deployment.
